# 礼簿助手 · 家庭查询

Password-encrypted static ledger for family use. Only the generic unlock page, app icon, manifest and authenticated encrypted payload are published here.

No access password, plaintext ledger data, personal notes, or unencrypted evidence photos are present in this repository. Decryption takes place in the visitor browser; the password is never sent to the hosting service.

The owner shares the site URL and family access password separately with intended family members. Possession of the password unlocks the entire ledger.
